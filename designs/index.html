เลือกดีไซน์

4 แบบนี้มีหน้าครบเหมือนกัน (login, ตั้งค่าครั้งแรก, โปรเจกต์ › repo, ประวัติการสแกน, ผลรวมทุก tool, เชื่อมต่อ CI/CD, ตั้งค่า, ผู้ใช้) และใช้ข้อมูลตัวอย่างชุดเดียวกัน ต่างกันที่การจัดวางและวิธีอ่านผล ลองกดใช้งานได้ทุกหน้า

A

Console

ธีมมืด ใกล้กับหน้าผู้ใช้ในรูปตัวอย่าง มี sidebar ซ้ายเป็น tree โปรเจกต์ › repo

  • ผลการสแกนเป็นตารางแน่น กรองได้ กดดูรายละเอียดด้านขวา
  • เหมาะกับคนที่ดูผลทุกวันและต้องการข้อมูลเยอะในจอเดียว
เปิดดีไซน์ A →
B

Report

ธีมสว่าง อ่านเหมือนรายงานความปลอดภัยจากบนลงล่าง ไม่มี sidebar

  • สรุปเป็นประโยคเดียวว่ามีอะไรใหม่ แล้วจัดกลุ่มตามไฟล์ พร้อม code snippet
  • เหมาะกับการส่งต่อให้หัวหน้าหรือคนที่ไม่ได้ดูทุกวัน
เปิดดีไซน์ B →
C

Triage

ธีมมืด 3 คอลัมน์ในจอเดียวเหมือนโปรแกรมอีเมล: repo › ประวัติสแกน › ผลลัพธ์

  • สลับ repo หรือครั้งที่สแกนได้โดยไม่เปลี่ยนหน้า ใช้คีย์บอร์ดได้
  • มีเครื่องหมาย + / − แบบ git diff บอกว่าอะไรใหม่หรือแก้แล้ว
เปิดดีไซน์ C →
Dแนะนำ

Simple

เรียบที่สุด หน้าน้อย แสดงเฉพาะสิ่งที่ต้องดูก่อน รายละเอียดกดขยายดู

  • แต่ละ repo บอกสถานะคำเดียว (ผ่าน / มี Critical 2) หน้า repo รวมประวัติและผลสแกนไว้ในหน้าเดียว
  • เปิดมาเห็นแค่ "ต้องดู" (ปัญหาใหม่ + Critical/High) ตัวกรองซ่อนไว้ สลับธีมสว่าง/มืดได้
เปิดดีไซน์ D →

นี่เป็นต้นแบบหน้าจอ ใช้ข้อมูลตัวอย่าง ยังไม่ได้ต่อ backend จริง login ด้วยชื่อและรหัสอะไรก็ได้ เมื่อเลือกแบบแล้วจะทำต่อเป็นระบบจริง (admin จาก env, ติดตั้งและอัปเดต scanner รายวัน, API สำหรับ CI/CD)
